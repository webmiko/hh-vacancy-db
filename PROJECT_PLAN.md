# План проекта: Поиск вакансий на hh.ru с подключением БД

## Описание проекта

Проект для получения данных о компаниях и вакансиях с сайта hh.ru, проектирования таблиц в БД PostgreSQL и загрузки полученных данных в созданные таблицы.

## Цели проекта

1. Получить данные о работодателях и их вакансиях с сайта hh.ru через публичное API
2. Спроектировать и создать таблицы в БД PostgreSQL

4. Реализовать класс DBManager для работы с данными
5. Создать пользовательский интерфейс

### 2.3. Создание SQL скриптов
**Задачи:**
- [ ] Создать SQL скрипт для создания БД:
  ```sql
  CREATE DATABASE hh_vacancies;
  ```
- [ ] Создать SQL скрипт для создания таблиц:
  ```sql
  CREATE TABLE employers (
      employer_id INTEGER PRIMARY KEY,
      name VARCHAR(255) NOT NULL,
      url VARCHAR(500),
      description TEXT,
      area VARCHAR(100),
      open_vacancies INTEGER
  );

  CREATE TABLE vacancies (
      vacancy_id INTEGER PRIMARY KEY,
      employer_id INTEGER NOT NULL,
      name VARCHAR(500) NOT NULL,
      url VARCHAR(500),
      salary_from INTEGER,
      salary_to INTEGER,
      currency VARCHAR(10),
      requirement TEXT,
      responsibility TEXT,
      published_at TIMESTAMP,
      CONSTRAINT fk_employer 
          FOREIGN KEY (employer_id) 
          REFERENCES employers(employer_id)
  );
  ```
- [ ] Создать индексы для оптимизации:
  ```sql
  CREATE INDEX idx_vacancies_employer_id ON vacancies(employer_id);
  CREATE INDEX idx_vacancies_salary_from ON vacancies(salary_from);
  CREATE INDEX idx_vacancies_name ON vacancies(name);
  ```

### 4.2. Создание класса DBManager
**Задачи:**
- [ ] Создать класс `DBManager` в `src/database/db_manager.py`:
  - Метод `get_companies_and_vacancies_count()` - список компаний и количество вакансий
    - SQL: `SELECT e.name, COUNT(v.vacancy_id) FROM employers e LEFT JOIN vacancies v ON e.employer_id = v.employer_id GROUP BY e.employer_id, e.name`
  - Метод `get_all_vacancies()` - все вакансии с информацией о компании
    - SQL: `SELECT e.name, v.name, v.salary_from, v.salary_to, v.currency, v.url FROM vacancies v JOIN employers e ON v.employer_id = e.employer_id`
  - Метод `get_avg_salary()` - средняя зарплата
    - SQL: `SELECT AVG(salary_from) FROM vacancies WHERE salary_from IS NOT NULL`
  - Метод `get_vacancies_with_higher_salary()` - вакансии с зарплатой выше средней
    - SQL: `SELECT * FROM vacancies WHERE salary_from > (SELECT AVG(salary_from) FROM vacancies WHERE salary_from IS NOT NULL)`
  - Метод `get_vacancies_with_keyword(keyword)` - вакансии по ключевому слову
    - SQL: `SELECT * FROM vacancies WHERE name LIKE %keyword%`
- [ ] Использовать параметризованные запросы (защита от SQL-инъекций)
