# HH Vacancy DB

Проект для получения данных о компаниях и вакансиях с сайта hh.ru, проектирования таблиц в БД PostgreSQL и загрузки полученных данных в созданные таблицы.

## Описание проекта

HH Vacancy DB — это консольное приложение для работы с вакансиями с платформы hh.ru и хранения данных в PostgreSQL. Проект позволяет:

- 🔍 Получать данные о работодателях и их вакансиях через API hh.ru
- 🗄️ Создавать и управлять структурой базы данных PostgreSQL
- 💾 Загружать данные о компаниях и вакансиях в БД
- 📊 Получать статистику и анализировать вакансии через SQL запросы
- 🔎 Искать вакансии по ключевым словам

## Особенности

- ✅ Работа с публичным API hh.ru
- ✅ Автоматическое создание БД и таблиц
- ✅ Связь между таблицами через внешние ключи
- ✅ Класс DBManager для удобной работы с данными
- ✅ Полная типизация кода
- ✅ Обработка ошибок с логированием
- ✅ Безопасное хранение данных для подключения к БД

## Установка

### Требования

- Python 3.9 или выше
- PostgreSQL (установленный и запущенный)
- Poetry (менеджер зависимостей)

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd hh-vacancy-db
```

2. Установите зависимости:
```bash
poetry install
```

3. Активируйте виртуальное окружение:
```bash
poetry shell
```

4. Настройте переменные окружения:
```bash
# Скопируйте шаблон .env.example в .env
cp .env.example .env

# Отредактируйте .env и укажите параметры подключения к PostgreSQL
DB_HOST=localhost
DB_PORT=5432
DB_NAME=hh_vacancies
DB_USER=postgres
DB_PASSWORD=your_password
```

5. Убедитесь, что PostgreSQL запущен и доступен

## Безопасность

### Защита конфиденциальных данных

Проект использует следующие меры безопасности:

1. **Переменные окружения**: Все конфиденциальные данные (пароли БД) хранятся в файле `.env`, который не коммитится в репозиторий.

2. **Правила безопасности**:
   - ❌ НИКОГДА не коммитьте файл `.env`
   - ❌ НИКОГДА не логируйте пароли и токены
   - ❌ НИКОГДА не добавляйте конфиденциальные данные в код
   - ✅ Используйте `.env.example` как шаблон
   - ✅ Проверяйте `git status` перед коммитом
