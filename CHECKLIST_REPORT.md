**Статус: ✅ ВЫПОЛНЕНО**

  - `DBCreator` - создание БД и таблиц
  - `DBManager` - работа с данными
  - `HeadHunterAPI` - взаимодействие с API
  - `Company`, `Vacancy` - модели данных
- **Open/Closed**: Классы расширяемы через наследование
- **Liskov Substitution**: Применимо к моделям данных
- **Interface Segregation**: Методы разделены по назначению
- **Dependency Inversion**: Используется инъекция зависимостей через параметры
